# Local fonts

These WOFF2 files are served locally so the site does not need to contact Google Fonts.

- `playpen-sans-latin.woff2`: Playpen Sans, variable weights 100–800. Source: [Google Fonts](https://fonts.google.com/specimen/Playpen+Sans).
- `playwrite-it-trad.woff2`: Playwrite IT Trad, variable weights 100–400. Source: [Google Fonts](https://fonts.google.com/specimen/Playwrite+IT+Trad).
